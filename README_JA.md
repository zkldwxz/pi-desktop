# pi-desktop

pi-desktop は [BaoCode](https://github.com/baocode-dev/baocode) から派生した、Pi コーディングエージェントを使う Flutter デスクトップアプリです。セットアップ、機能、制限については [英語の README](README.md) を参照してください。デスクトップパッケージは macOS と Windows 向けです。

アプリは [GPL-3.0-only](LICENSE) で提供されます。エディターとターミナルのパッケージ（`bao_editor`、`bao_xterm`、`bao_pty`）は MIT ライセンスです。Pi およびその他の第三者コンポーネントにはそれぞれのライセンスが適用されます。上流の著作権表示とライセンス通知も保持されています。
