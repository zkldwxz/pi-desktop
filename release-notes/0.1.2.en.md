# pi-desktop 0.1.2

- Desktop workspace powered by the Pi coding agent, with an independent application identity, data directory, browser integration and signed update channel.
- Pi uses native provider protocols for supported standard APIs and records cache-read and cache-write usage when the provider reports it. No higher cache hit rate, speed or cost advantage has been measured.
- The bundled Pi runtime starts at 1.5.0 and can install official stable updates independently for new local sessions.
- Direct SSH Pi sessions use Pi and Node on the remote host with batch/key authentication. A real SSH stub turn has been verified; broader remote workflows remain under validation.
- Includes macOS Apple Silicon and Intel ZIP/DMG packages and a Windows x64 installer. Linux desktop packages are excluded.
- Corrects the macOS packaging architecture check and verifies that the bundled Pi CLI starts on each build platform.
- macOS packages use ad-hoc signing and are not notarized. The Windows installer is unsigned; operating systems may show security prompts.
