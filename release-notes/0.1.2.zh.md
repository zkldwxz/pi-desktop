# pi-desktop 0.1.2

- 使用 Pi coding agent 内核，具备独立的应用标识、数据目录、浏览器集成和签名更新渠道。
- 支持标准 API 的 Pi 原生供应商协议，并在供应商返回数据时记录缓存读取、缓存写入用量。尚无实测数据证明比上游的缓存命中率更高、速度更快或成本更低。
- 随包 Pi 初始版本为 1.5.0，可独立安装官方稳定更新，供后续启动的本地会话使用。
- 直接 SSH Pi 会话使用远程主机已有的 Pi 和 Node，通过批处理/密钥认证；真实 SSH stub 对话已验证，更多远程工作流仍待验证。
- 提供 macOS Apple Silicon、Intel 的 ZIP/DMG 包，以及 Windows x64 安装器。本次不构建 Linux 桌面安装包。
- 修正 macOS 打包架构检查，并在各构建平台验证随包 Pi CLI 能正常启动。
- macOS 包采用 ad-hoc 签名且未经公证；Windows 安装器未签名，系统可能显示安全提示。
