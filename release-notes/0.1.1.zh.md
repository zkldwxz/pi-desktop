# pi-desktop 0.1.1

- 使用 Pi coding agent 的桌面工作区，具有独立应用标识与数据目录。
- Pi 对受支持的标准 API 使用原生供应商协议，并在供应商提供数据时按请求记录缓存读取与写入。缓存效果取决于供应商与工作负载，目前没有实测更高命中率。
- 随包 Pi 运行时初始为 1.5.0，可从 Pi 官方发布端点独立更新，供新启动的本地会话使用；桌面应用使用独立签名更新渠道。
- 直接 SSH Pi 会话使用远程主机已安装的 Pi 和 Node，通过批处理/密钥认证；真实 SSH stub 对话已验证，更多远程工作流仍待验证。
- 本次计划发布 macOS 和 Windows 安装包，打包及安装验证仍待完成；不构建 Linux 安装包。
