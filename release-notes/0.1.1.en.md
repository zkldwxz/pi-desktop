# pi-desktop 0.1.1

- Desktop workspace using the Pi coding agent, with an independent application identity and data directory.
- Pi uses native provider protocols for supported standard APIs and reports provider cache-read and cache-write usage per request when available. Cache results depend on the provider and workload; no higher hit rate has been measured.
- The bundled Pi runtime starts at 1.5.0 and can update independently from the official Pi release endpoint for new local sessions. Desktop updates use a separate signed release channel.
- Direct SSH Pi sessions use Pi and Node installed on the remote host with batch/key authentication. A real SSH stub turn has been verified; broader remote workflows remain under validation.
- macOS and Windows packages are planned for this release; package and installation validation is pending. No Linux packages are being built.
