# pi-desktop 0.1.3

- 修复添加自定义上游后，对话仍沿用 PI 内置 Anthropic 模型的问题。模型选择仅来自“设置 → 模型”中已启用的上游；空配置会提示添加模型，不再启动内置默认模型。
- 上游地址、密钥和模型修改会在下一轮生效，包括排队消息，并保留原会话。已移除或禁用的模型选择会回退到有效的已配置模型。
- 设置中的模型测试现在实际请求当前页面的上游和模型，也可测试尚未启用的模型。
- 移除 PI 不支持的 Claude CLI 设置、角色分层、提示建议、署名控件及旧自定义入口，修正模型、网络和用量说明。
- 增加空配置启动、旧模型选择、启动时修改配置、排队消息和真实 PI 端点切换的回归测试。

已有上游配置、密钥和对话记录会保留。macOS 包仍采用 ad-hoc 签名且未经公证，Windows 安装器未签名。
