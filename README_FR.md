# pi-desktop

pi-desktop est une application de bureau Flutter utilisant l'agent de programmation Pi, issue de [BaoCode](https://github.com/baocode-dev/baocode). Consultez le [README en anglais](README.md) pour l'installation, les fonctionnalités et leurs limites. Les paquets de bureau ciblent macOS et Windows.

L'application est distribuée sous [GPL-3.0-only](LICENSE). Les paquets d'éditeur et de terminal (`bao_editor`, `bao_xterm` et `bao_pty`) conservent leur licence MIT. Pi et les autres composants tiers conservent leurs propres licences. Les mentions de droits d'auteur et de licence du projet d'origine sont conservées.

Ce projet est indépendant d'Anthropic et n'est pas approuvé par cette entreprise.
