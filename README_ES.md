# pi-desktop

pi-desktop es una aplicación de escritorio Flutter que utiliza el agente de programación Pi y deriva de [BaoCode](https://github.com/baocode-dev/baocode). Consulta el [README en inglés](README.md) para conocer la instalación, las funciones y sus limitaciones. Los paquetes de escritorio son para macOS y Windows.

La aplicación se distribuye bajo [GPL-3.0-only](LICENSE). Los paquetes de editor y terminal (`bao_editor`, `bao_xterm` y `bao_pty`) conservan sus licencias MIT. Pi y los demás componentes de terceros conservan sus propias licencias. Se mantienen los avisos de derechos de autor y licencia del proyecto original.

Este proyecto es independiente de Anthropic y no cuenta con su respaldo.
